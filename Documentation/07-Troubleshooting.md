# Azure Troubleshooting

## Overview

This document summarizes the troubleshooting methodology used throughout the Azure Cloud Support & Administration Lab.

## Troubleshooting Methodology

### 1. Identify the Problem

Gather:

- User report
- Error message
- Affected resource
- Expected behavior
- Actual behavior
- Scope of impact

### 2. Establish a Theory

Identify likely causes based on the symptoms.

### 3. Test the Theory

Use Azure configuration, logs, metrics, networking information, permissions, and resource status to test possible causes.

### 4. Establish a Plan

Select the least disruptive corrective action.

### 5. Implement the Fix

Apply the configuration change.

### 6. Verify Functionality

Confirm that the original problem is resolved.

### 7. Document the Incident

Record:

- Symptoms
- Investigation
- Root cause
- Resolution
- Verification
- Preventive recommendations
